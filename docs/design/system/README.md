# Portfolio Twin

ソフトウェアエンジニア [氏名] のポートフォリオサイトのためのデザインシステム。ビジョン「ICTを基盤として、AIとビッグデータを活用し、人々の生活から無駄を取り除き、人生に有益な時間を最大化できる世界を実現する」を、**夜(テクノロジー)から昼(暮らし)へ**という二つのトーンで表す。

## コンセプト:Twin

| ゾーン | テーマ | 使う場所 | 意味 |
|---|---|---|---|
| Night | `night` | Home の3Dシーン、全ページのヘッダーとフッター、About のビジョン帯 | テクノロジーの基盤。街をつなぐネットワーク |
| Day | `day` | Projects、Project詳細、Experience、Blog、About の本文 | 暮らしと、読みやすさ。事例や経歴をじっくり読ませる |

夜のゾーンは要素に `data-theme="night"` を付けて切り替える。同じトークン名(`--bg`、`--ink`、`--link` など)がテーマごとに値を持つので、コンポーネント側は色を直書きしない。

## 文章の基本

- 日本語。です・ます調は使わず、言い切りの体言止め・常体で簡潔に書く(例:「何を、誰のために作ったか」)。
- 技術用語は正確に。初出の略語は括弧で補う(例:V2X(Vehicle-to-Everything))。
- 数値は事実だけ。公開できない数値は丸めるか、定性的な表現にする。
- 英字ラベル(`PROJECTS`、`01 — ICT`)は `label` スタイルの等幅で、装飾としてのみ使う。本文に英語を混ぜない。

## 色の使い方

- 文字は `--ink`、補助は `--ink-muted`。どちらも両テーマの `--bg` と `--surface` 上で 4.5:1 を満たす。
- `--accent-cyan` は「技術」、`--accent-amber` は「暮らし」。1画面にアクセントは2色まで。
- Day の白地にシアンを文字色で載せない(コントラスト不足)。Day でシアンを使うのは `--night-box` の中だけ。
- アンバーとシアンの塗りの上の文字は `--on-accent`。
- タグ:業務 = アンバー、個人開発 = `--tag-personal-*`。色だけに頼らず、必ず文字ラベルを付ける。
- グラデーション、影、左端だけの色付き罫線は使わない。面の区別は `--surface` と `--line` で行う。

## タイポグラフィ

- 和文・欧文とも **BIZ UDPゴシック** 1書体(`--font-sans`)。等幅は **JetBrains Mono**(`--font-mono`)。どちらも Google Fonts から読み込む:
  `https://fonts.googleapis.com/css2?family=BIZ+UDPGothic:wght@400;700&family=JetBrains+Mono:wght@400;500&display=swap`
- 太さは 400 と 700 の2段階のみ。
- `display` は1画面に1回。ページタイトルは `h1`、セクション見出しは `h2`。
- 本文の1行は全角35〜40字。記事本文の幅は 720px。

## 余白とレイアウト

- 4px 基準。`space-*` 以外の値を使わない。
- コンテンツ幅は `container-max`(1120px)、左右の余白はモバイルで `space-4`、デスクトップで `space-6`。
- セクション間はデスクトップ `space-24`、モバイル `space-16`。
- 押せる要素はすべて `touch-target`(44px)以上。

## 角丸

カードと図版は `radius-lg`、ボタンは `radius-md`、図解の箱とコードチップは `radius-sm`、タグとフィルターは `radius-pill`。

## 図解

- 箱 = `--surface` か白地に `--line-strong` の 1px 枠、`radius-sm`。矢印は `--ink-muted`。
- 主役の要素だけ `--night-box` の塗りに `--accent-cyan` の文字。1枚の図で主役は1〜2個まで。
- キャプションは `caption` スタイルで図の下に置く。
- 3Dシーンの語彙(光る細線、ノード)を図解でも使ってよいが、Night ゾーンに限る。

## アイコン

- 線のアイコン(1.5px、角丸の端点)。サイズは 20px、`--ink` か `--ink-muted`。
- GitHub・LinkedIn は各社の公式マークをそのまま使い、改変しない。アイコンだけのボタンには `aria-label` を付ける。
- 絵文字は使わない。

## 動き

- アニメーションは Home の3Dシーンに集中させる。UIの遷移は 150〜200ms のフェードのみ。
- `prefers-reduced-motion: reduce` では3Dを静止画のポスターに置き換え、UIのトランジションも切る。

## アクセシビリティ

- フォーカスは `--focus` の 2px リング、オフセット 2px。
- 色の区別は明度差も付ける。リンクは下線(ホバー時、または本文中は常時)。
- 3Dシーンには画面上のキャプションと同じ文をHTMLとしても置く(読み上げ・SEO)。

## コンポーネント

Header(Night)、Button、Tag、ProjectCard、SectionLabel、SceneCaption(Night)、Diagram。各カードのガイドラインを参照。
