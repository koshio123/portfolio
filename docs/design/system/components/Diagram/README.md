# Diagram

プロジェクト詳細の「全体図」に使う、抽象化したアーキテクチャ図の描き方。

- 地は `--surface`、`radius-lg` の枠に入れ、内側余白 `space-8`。
- 箱:`--bg` の塗り、`--line-strong` の 1px 枠、`radius-sm`、`small` スタイル。
- 主役の箱(1〜2個):`--night-box` の塗りに `--accent-cyan` の太字。
- 矢印・接続線:`--ink-muted` の 1.5px。データの流れは実線、制御や任意の流れは破線。
- 下に `caption` スタイルで「図 n」と説明を付ける。
- 実装は SVG で書き、色はすべて CSS 変数で指定する(両テーマで崩れないように)。
- 利用側が用意するもの:箱と接続の構成、主役の指定、キャプション。
