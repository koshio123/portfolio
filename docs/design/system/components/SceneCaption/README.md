# SceneCaption

Home の3Dシーンに重ねる、幕ごとのキャプションと進行インジケーター。常に Night ゾーン。

- キャプション:`label`(`01 — ICT`、`--link` のシアン)+ `display` 相当の見出し(モバイルでは `h1` サイズ)。画面左下、`space-12` 内側。
- 進行インジケーター:画面右の縦並び。5項目(00 混沌 / 01 ICT / 02 DATA / 03 AI / 04 VISION)。現在の幕だけシアンで塗り、ほかは `--ink-muted` の枠だけ。`aria-current="step"` を付ける。
- キャプション文は3D描画と別に HTML として出力する(読み上げ・SEO)。
- 3D の上なので、文字の背後の映像が明るくなる第4幕では文字色を `--on-accent` に切り替える。
- 利用側が用意するもの:現在の幕、幕ごとのキャプション文。
