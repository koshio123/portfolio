# ProjectCard

Projects 一覧のカード。上に全体図または画面、下に種別タグ・タイトル・概要・技術チップ。

- 枠は `--line`、`radius-lg`、塗りは `--bg`。図の領域は高さ 200px、`--surface`。
- タイトルは `h3`、概要は `small` で `--ink-muted`、2行で省略。
- カード全体を1つの `<a>` にする(中にボタンを入れない)。ホバーで枠を `--line-strong` に。
- 図がない場合は Diagram の簡易版(主要な箱3つ)を置く。写真やイラストで代用しない。
- 利用側が用意するもの:種別、タイトル、概要、技術、図または画面のサムネイル、リンク先。
