# Tag

プロジェクトの種別(業務・個人開発)と、技術スタックのチップ。

- 種別タグ:`radius-pill`、`caption` スタイル、左右余白 `space-3`。業務 = `--accent-amber` の塗りに `--on-accent`、個人開発 = `--tag-personal-bg` / `--tag-personal-ink`。
- 技術チップ:`code` スタイル(12px)、`--line-strong` の枠、`radius-sm`。塗りなし。
- タグは押せない表示要素。絞り込み用のチップは別(Button の副ボタンを `radius-pill` にしたもの)。
- 利用側が用意するもの:種別、技術名。
